# AWS Disaster Recovery Solution

## 📌 Overview

This project demonstrates a Disaster Recovery (DR) solution using AWS cloud services.

The system is designed to improve availability, automate failover processes, and reduce downtime during failures.

---

## 🛠️ Technologies Used

* Amazon S3 – Backup storage and versioning
* AWS Route 53 – DNS failover
* AWS Lambda – Automated failover logic
* AWS CloudFormation – Infrastructure automation

---

## ⚙️ Workflow

1. Store backup data in Amazon S3
2. Enable versioning for recovery
3. Configure Route 53 health checks
4. Use Lambda for automatic failover
5. Deploy infrastructure using CloudFormation

---

## 🔥 Features

* Automated disaster recovery
* DNS failover support
* High availability
* Backup and restore mechanism
* Reduced downtime
